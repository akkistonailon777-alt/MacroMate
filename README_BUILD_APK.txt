MACROMATE — сборка APK без Android Studio

1. Открой https://github.com и войди в аккаунт.
2. Нажми + в правом верхнем углу → New repository.
3. Название: MacroMate. Выбери Public или Private, затем Create repository.
4. На странице нового репозитория нажми Add file → Upload files.
5. Открой распакованную папку проекта и перетащи ВСЕ файлы и папки проекта, включая скрытую папку .github, в окно загрузки GitHub. Если скрытая папка не отображается, включи показ скрытых файлов в проводнике.
   Важно: загружай содержимое проекта, а не ZIP-архив целиком.
6. Нажми Commit changes.
7. Открой вкладку Actions в репозитории. Выбери Build MacroMate APK слева, если workflow виден, затем Run workflow. Если сборка уже запустилась после загрузки — открой самый новый запуск.
8. Дождись зелёной галочки. Открой запуск сборки, найди раздел Artifacts внизу и скачай MacroMate-debug-apk.
9. Распакуй скачанный ZIP. Внутри будет app-debug.apk. Перешли его на Android и открой для установки.

Если GitHub не показывает workflow, проверь, что папка .github/workflows/build-apk.yml загрузилась в корень репозитория.
Это тестовая debug-сборка; первый запуск может занять несколько минут. Если сборка упадёт, открой её и пришли скриншот ошибки.
